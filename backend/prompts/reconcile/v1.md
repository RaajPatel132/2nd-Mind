2nd Mind is about to save a memory. Some stored memories look similar. Decide how the new one
relates to them. Clear cases (the same fact with a new value, an episode that fulfils a wish)
were already handled by code; you only see the unclear ones.

New memory:
{{ proposed }}

Stored memories that look similar:
{{ candidates }}

Choose one decision:

- new: it is a different thing; save it as its own memory. Two different shows, two different
  runs, two different ideas are always new.
- add_detail: it is the same thing and adds detail to a stored memory (pick that candidate).
- supersede: it replaces a stored memory that is no longer true, or moves a plan to another
  time (pick the replaced candidate).
- fulfil: it completes a stored wish or intention (pick it).
- link: it is related to a stored memory but separate (pick it).
- no_op: it is an exact duplicate of a stored memory; nothing new to save (pick it).

Never merge two things that happened on different occasions. Return the decision, the candidate
id (c1, c2, ...) or null for new, and one short sentence saying why.
